    Research Notes 02

    How to reproduce the code

    ​ In scientific research, we usually need to reproduce the code. But how should we reproduce it? And do we need to simply complete the process, or obtain graphs similar to those in the paper?

    ​ One opinion I agree with says that we first need to run the code. This means we need to check the path, dependencies, and environment to ensure they fit our device. Then we need to print out the data flow direction. Then we can add comments to the code. This is a fast way to help us understand the code and quickly get started, but it won’t be comprehensive.

    ​ There are many opinions about how to improve out coding ability. But in summary, there is a common step: adding comments to the code. So it is obviously that we cannot avoid understanding the code. AI is a good way to get a result easily, but it is not healthy for our ability.
